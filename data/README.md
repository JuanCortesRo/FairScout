# Datos de prueba

- `cvs/`: CVs seleccionados del Kaggle "Resume Dataset" (PDF y DOCX).
- `vacantes/`: vacantes de Kaggle "LinkedIn Job Postings" o del SPE.
- `set_dorado/`: 10-15 CVs anotados a mano para medir calidad.

Ver la sección 3 de `docs/BASE_PROYECTO.md`. Antes de subir CVs al repositorio, confirmar que vienen
anonimizados y que la licencia del dataset lo permite; si no, mantenerlos solo en el servidor (sección 24.3).
